このサイトについて

何をしているサイトか

国会ウォッチは、国会会議録検索システム（国立国会図書館）が公開している API から、衆議院・参議院の本会議と委員会の会議録を毎日自動で取り込み、 「その日の国会で何が話されたか」を一目で分かる形に組み直している個人のサイトです。掲載しているのは直近 1 年分です。

会議録そのものは長大で、1 つの委員会でも数万字あります。このサイトは全文を並べ直すのではなく、

  • その会議の議題（会議録冒頭の「本日の会議に付した案件」）
  • 誰が何回、何文字話したかの一覧
  • 各発言の冒頭だけの抜粋（全文は国会会議録検索システムへのリンク）
  • 発言の本文から機械的に数えたよく出た語

を出すことで、読む前に当たりを付けられるようにしています。全文は必ず出典元でご確認ください。

更新のしかた

GitHub Actions が毎朝 1 回動き、API から新しい会議録を取り込んでページを作り直し、GitHub Pages に配信しています。人手は入っていません。

会議録は会議が開かれてから 3〜5 週間ほど後に公開されます。そのため、きのう開かれた委員会がすぐこのサイトに出るわけではありません。 ここでいう「最新」は、会議録として公開されたもののうち、いちばん新しい開催日のことです。

数え方について

  • 発言回数は、会議録上で発言者が切り替わった回数です。短い進行の合いの手も 1 回と数えます。委員長・議長の回数が多くなるのはそのためです。
  • よく出た語は、漢字 2 文字以上・カタカナ 3 文字以上・英字 3 文字以上のまとまりを機械的に数えたものです。形態素解析は使っていないため、語の切れ目がずれることがあります。 「委員長」「答弁」などの手続き上の語はあらかじめ除いています。
  • 発言の抜粋は冒頭 160 字程度です。会議によっては発言数が多いため、長い発言から 120 件までを載せています。
  • 同姓同名の方は区別していません。会派・役職は、その会議録に記録されていたものを使っています。

出典と利用について

データの出典は国会会議録検索システム（国立国会図書館）です。会議録は国会の公的な記録であり、同館の 検索用 API を通じて取得しています。 このサイトは国立国会図書館および国会とは関係のない、個人が作った非公式のサイトです。

内容の正確性については、取り込み・集計の過程で誤りが生じる可能性があります。重要な判断には必ず出典元の会議録をお使いください。
