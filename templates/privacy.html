プライバシーポリシー

個人情報の取得について

国会ウォッチ（以下「当サイト」）は、あらかじめ作られた HTML ファイルを配信しているだけの静的サイトです。 お問い合わせフォームや会員登録はなく、当サイトが閲覧者の氏名・メールアドレス等を入力してもらうことはありません。

アクセス情報について

当サイトは GitHub Pages（GitHub, Inc.）で配信しています。ページの表示にあたり、同社のサーバーが IP アドレス・ブラウザの種類などのアクセス情報を記録することがあります。取り扱いは GitHub のプライバシーに関する声明に従います。

Cookie・アクセス解析について

当サイトは Cookie を使用しません。現時点でアクセス解析ツールおよび広告は導入していません。 今後導入する場合は、このページに内容を追記します。

外部サイトへのリンク

当サイトには国会会議録検索システム（国立国会図書館）をはじめとする外部サイトへのリンクがあります。 リンク先での個人情報の取り扱いについては、各サイトの方針をご確認ください。

掲載内容の免責

当サイトの内容は、国会会議録検索システムの公開 API から機械的に生成しています。 集計や抜粋の過程で誤りが生じる可能性があり、内容の正確性・完全性を保証するものではありません。 当サイトの利用によって生じた損害について、運営者は責任を負いかねます。

改定

本ポリシーは必要に応じて改定します。改定後の内容は、このページに掲載した時点から適用します。
